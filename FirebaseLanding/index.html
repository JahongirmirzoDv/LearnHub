LearnHub

A web-based learning system where students browse computing courses, enrol, work through lessons, take quizzes and follow their progress, while administrators run the whole catalogue. Guests can search and preview everything without an account.

Three lines, one hub

Each kind of user travels a different route through LearnHub. Every stop below is a working part of the application.

  1. Guest

    • Home page with the category map
    • Search, filter and sort the catalogue
    • Course details and course route
    • Free preview lessons
    • Register and log in
    • About and contact form

  2. Student

    • Dashboard with progress and activity
    • Enrol in or leave courses
    • Articles, videos, PDFs and images
    • Mark lessons complete
    • Take quizzes with instant marking
    • Answer review and result history
    • Profile and password change

  3. Administrator

    • Dashboard with live figures
    • Courses, categories and resources
    • Validated file uploads
    • Quizzes, questions and answers
    • Users, roles and enrolments
    • Quiz results and contact inbox

How it is built

A server-rendered ASP.NET Core MVC application. Controllers stay thin, services hold the rules, and Entity Framework Core talks to the database.

Security

Bootstrap 5.3 with a custom design system, Overpass typeface, client and server validation

GitHub for source control, GitHub Actions for CI, Railway for the application, Firebase Hosting for this site

Data model

Eleven application tables plus the ASP.NET Core Identity tables. Unique indexes stop duplicate enrolments and answers, and delete rules protect quiz history.

Checked on every push

GitHub Actions builds the solution and runs the full test suite before anything is deployed.

211 automated tests
Unit, service, data-model and integration tests drive the real application in memory, including a crawler that follows every link as a guest, a student and an administrator.
42 browser checks
Playwright walks the guest, student and administrator journeys on desktop, tablet and phone sizes, failing on console errors, broken images or sideways scrolling, and axe-core finds no WCAG 2.2 A or AA violations.
Every CRUD path covered
Courses, categories, resources, quizzes, questions, answers, enrolments and users are created, read, updated and deleted through the same code the interface calls.
Security by default
Role checks on every protected action, ownership checks against direct object references, antiforgery tokens, encoded output, signature-checked uploads and no secrets in the repository.

Deployment

The brief rules out Azure, so the project runs on Railway with Firebase Hosting for this presentation page.

Railway
Builds the Dockerfile and runs the ASP.NET Core MVC application, listening on the port Railway supplies in PORT.
Railway volume
Mounted at /data and holds the SQLite database, the Data Protection key ring and administrator uploads, so a redeploy keeps its data.
Firebase Hosting
Serves this static presentation page from the FirebaseLanding/ folder. Firebase cannot execute an ASP.NET Core application, so it links to Railway instead.
GitHub
Source control and the CI workflow that builds the solution and runs the tests on every push.

About the assignment

LearnHub was built for the group assignment of CT050-3-2-WAPP Web Applications at Asia Pacific University of Technology & Innovation. The brief asks for a database-driven web application with public and member areas, an administration area, validation, security and a written report.
